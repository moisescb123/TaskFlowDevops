## Original

Como Desarrollador quiero eliminar una tarea del tablero para retirar actividades que ya no aplican al proyecto.

## Enhanced

**Story:** As a Developer, I want to delete a task from the board so that activities that no longer apply are removed.

**Priority:** Medium | **Related:** RF03, RNF02, RNF03

### Behavior

1. Developer chooses delete on a task.
2. UI asks for confirmation before proceeding.
3. On confirm, backend deletes the task; card disappears without full reload when practical.
4. On cancel, task remains unchanged.
5. Viewer cannot delete (`403`). Deleted task does not reappear after restart.

### Fields and validations

- Path param `taskId` required; unknown id → `404`.
- Confirmation is a UI concern; API deletes on authorized DELETE.

### Acceptance criteria

- **AC1:** Given Developer confirms delete, when DELETE succeeds, then `204` and the task is gone from the board.
- **AC2:** Given Developer cancels confirmation, when they return to the board, then the task remains.
- **AC3:** Given Viewer, when they DELETE, then `403`.
- **AC4:** Given unknown taskId, when DELETE is called, then `404`.
- **AC5:** Given successful delete, when app restarts, then the task does not return (RNF02).

### Endpoints

- `DELETE /api/tasks/{taskId}` → `204` / `403` / `404` / `401`
