# Step 8.3 Report - Curl Endpoint Testing

- Date: 2026-10-29
- Change: us02-user-logout
- Base URL: http://127.0.0.1:5000
- Database: `taskflow-us02-curl.db` (seeded demo users)

## Commands Executed

```bash
# Anonymous logout → 401
curl.exe -s -X POST http://127.0.0.1:5000/api/auth/logout

# Admin login → 200
curl.exe -s -c cookies.txt -b cookies.txt -X POST http://127.0.0.1:5000/api/auth/login \
  -H "Content-Type: application/json" --data-binary @login.json

# me before logout → 200
curl.exe -s -c cookies.txt -b cookies.txt http://127.0.0.1:5000/api/auth/me

# logout → 204; Set-Cookie session expired (Max-Age=0)
curl.exe -s -c cookies.txt -b cookies.txt -X POST http://127.0.0.1:5000/api/auth/logout -D headers.txt

# me after → 401
curl.exe -s -c cookies.txt -b cookies.txt http://127.0.0.1:5000/api/auth/me

# board after → 302 /login?next=/board
curl.exe -s -o NUL -w "%{http_code} %{redirect_url}" -c cookies.txt -b cookies.txt \
  http://127.0.0.1:5000/board
```

- anon logout → `401 Unauthorized`
- authenticated logout → `204` with expired session cookie
- subsequent `/api/auth/me` → `401`
- subsequent `/board` → `302` to login
- User table unchanged (logout does not mutate users)
